# speed_test
Тестовое задание для компании "Это легко" на позицию Fullstack-разработчика

Консольный скрипт на Python для замера скорости скачивания данных с указанного URL.

## Как запустить

1. Убедитесь, что у вас установлен Python 3.x.
2. Установите необходимые зависимости:
    ```
    bash
    pip install requests
    ```
3. Запустите скрипт
    ```
    python3 speed_test.py
    ```
